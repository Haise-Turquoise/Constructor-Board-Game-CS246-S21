Methods:
-	rollDice: an integer (between 2-12) read from the input, which will be set to the current dice value

-	beStolen: return resource type that is be stolen from the player, used in Geese movement. The probability is calculated by number of each resources to the total resources.
-	loseHalfResource: randomly lose a half of total resources, probability is determined by uniform

-	initRandBoard: used for command line argument “-random-board”, initialize the board resource type distribution and tile value randomly
-	initSeedBoard: used for command line argument “-seed”, initialize the board resource type distribution and tile value by seed number
